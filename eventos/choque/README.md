# CHOQUE — SLT × MTY

Flyer e identidad para la fecha en Beer Therapy (Saltillo) con Cenicero, Nova Doler, Adobes Buenos y acordeacorde.

- `flyer.html` — todo el diseño en un archivo. Los datos (fecha, horarios, bandas) están en el objeto `EV` al inicio del script.
- Ver un formato: abrir `flyer.html?f=post` · `?f=story` · `?f=cuadro` · `?f=identidad`
- Exportar PNG: `node eventos/choque/exportar.js` (1x para redes) o `node eventos/choque/exportar.js 2` (2x para imprimir).

Concepto: Saltillo (adobe, Fraunces itálica, trazo a mano) y Monterrey (acero, Archivo condensada, retícula) separados por una falla roja diagonal. Todo lo que cruza la falla cambia de mundo.
